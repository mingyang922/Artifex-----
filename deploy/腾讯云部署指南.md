# 腾讯云服务器部署 Artifex 指南

## 一、腾讯云控制台操作

### 1. 购买服务器

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 进入 **云服务器 CVM** → **实例** → **新建**
3. 推荐配置：
   - 地域：选择离你最近的（如广州、上海、北京）
   - 镜像：**Ubuntu 22.04 LTS**
   - 规格：**2核4GB**（轻量应用服务器也可以）
   - 带宽：**5Mbps** 起
   - 系统盘：**50GB SSD**

### 2. 购买域名

1. 进入 **域名注册** 页面搜索并购买域名
2. `.com` 域名约 60-80 元/年
3. 购买后需要实名认证

### 3. 域名解析

1. 进入 **DNSPod**（腾讯云默认使用 DNSPod）
2. 添加两条 A 记录：

| 主机记录 | 记录类型 | 记录值 | TTL |
|----------|----------|--------|-----|
| @ | A | 你的服务器公网IP | 600 |
| www | A | 你的服务器公网IP | 600 |

### 4. 安全组配置

1. 进入 **云服务器** → **安全组**
2. 添加入站规则：

| 类型 | 来源 | 协议端口 | 策略 |
|------|------|----------|------|
| HTTP | 0.0.0.0/0 | 80 | 允许 |
| HTTPS | 0.0.0.0/0 | 443 | 允许 |
| SSH | 0.0.0.0/0 | 22 | 允许 |

## 二、连接服务器

### Windows 用户

使用 **PuTTY** 或 **Windows Terminal**：

```bash
ssh root@你的服务器公网IP
```

输入密码（购买时设置的密码）。

### 获取服务器公网IP

在腾讯云控制台 → 云服务器 → 实例列表中查看。

## 三、上传项目代码

### 方式一：使用 Git（推荐）

1. 先将代码推送到 Gitee 或 GitHub：

```bash
# 在本地项目目录执行
cd "c:\Users\yang\Desktop\Artifex软著申请版"

# 初始化 Git（如果还没有）
git init
git add .
git commit -m "初始提交"

# 添加远程仓库（以 Gitee 为例）
git remote add origin https://gitee.com/你的用户名/artifex.git
git push -u origin master
```

2. 在服务器上克隆：

```bash
cd /var/www
git clone https://gitee.com/你的用户名/artifex.git
```

### 方式二：使用 SCP 上传

在本地 Windows 的 PowerShell 中执行：

```powershell
scp -r "c:\Users\yang\Desktop\Artifex软著申请版" root@你的服务器IP:/var/www/artifex
```

### 方式三：使用 FileZilla

1. 下载安装 [FileZilla](https://filezilla-project.org/)
2. 连接信息：
   - 主机：`sftp://你的服务器IP`
   - 用户名：`root`
   - 密码：你的服务器密码
   - 端口：`22`
3. 将项目文件夹拖到 `/var/www/artifex`

## 四、执行部署

```bash
# 进入项目目录
cd /var/www/artifex

# 给部署脚本执行权限
chmod +x deploy/deploy.sh

# 修改配置（编辑脚本中的域名和邮箱）
nano deploy/deploy.sh
# 修改 DOMAIN="你的域名"
# 修改 EMAIL="你的邮箱"

# 执行部署
sudo bash deploy/deploy.sh
```

## 五、配置环境变量

部署完成后，编辑配置文件填写 API Key：

```bash
nano /var/www/artifex/config/.env
```

填写以下内容：

```env
NODE_ENV=production
PORT=3000
SESSION_SECRET=（脚本自动生成的）

# 腾讯混元 API（如果使用）
HUNYUAN_SECRET_ID=你的ID
HUNYUAN_SECRET_KEY=你的Key

# 阿里通义万相（如果使用）
DASHSCOPE_API_KEY=你的Key

# 即梦 AI（如果使用）
IMAGE_API_KEY=你的Key
```

保存后重启应用：

```bash
pm2 restart artifex
```

## 六、申请 SSL 证书（HTTPS）

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 申请证书
sudo certbot --nginx -d 你的域名 -d www.你的域名

# 按提示输入邮箱并同意条款
```

证书会自动续期。

## 七、验证部署

1. 浏览器访问 `http://你的域名`（HTTP）
2. 配置 SSL 后访问 `https://你的域名`（HTTPS）
3. 应该能看到 Artifex 登录页面

## 常用命令速查

```bash
# 应用管理
pm2 status              # 查看状态
pm2 logs artifex        # 查看日志
pm2 restart artifex     # 重启
pm2 stop artifex        # 停止

# 更新代码
cd /var/www/artifex
git pull                # 拉取最新代码
npm install --production  # 更新依赖
pm2 restart artifex     # 重启应用

# Nginx 管理
sudo nginx -t           # 测试配置
sudo systemctl reload nginx  # 重载配置

# 查看错误日志
tail -f /var/log/nginx/error.log
```

## 常见问题

### Q: 域名无法访问？

1. 检查 DNS 解析是否生效：`ping 你的域名`
2. 检查安全组是否开放 80/443 端口
3. 检查 Nginx 是否运行：`sudo systemctl status nginx`

### Q: 502 Bad Gateway？

```bash
# 检查应用是否运行
pm2 status

# 如果没有运行，启动它
pm2 start backend/proxy.js --name artifex
```

### Q: 如何查看实时日志？

```bash
pm2 logs artifex --lines 50
```

### Q: 忘记数据库位置？

SQLite 数据库在 `backend/data/` 目录下。
