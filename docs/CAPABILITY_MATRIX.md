## 状态定义

- **稳定**：存在真实后端闭环，并被自动化测试覆盖，可用于当前单机生产部署。
- **简化版**：解决部分业务问题，但不能宣称具备完整模型或算法能力。
- **外部集成依赖**：平台侧编排已完成，真实执行依赖未内置的外部服务。
- **未完成/未实现**：不得在产品介绍中描述为已交付能力。

## 运行时能力 API

登录后可通过 `GET /api/capabilities` 查询当前部署的实际能力。客户端应以该接口的 `enabled`、`status`、`description` 和 `limitations` 为准，不应仅根据页面是否存在推断功能可用。
