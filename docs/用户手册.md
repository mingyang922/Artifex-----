# Artifex 用户手册 V1.3.3

## 一、平台简介

Artifex 是一个面向 2D 游戏美术资产生产的协作平台，集成了 AI 辅助生成、项目管理、素材库管理、风格预设和用户中心等功能。平台支持多种 AI 服务商（即梦 Seedream、腾讯云、阿里云通义万相、SD WebUI），可快速完成文生图、图生图、风格迁移、图片放大、背景去除以及角色动作组批量生成等操作，帮助游戏美术团队高效产出高质量 UI 资产与角色动画素材。

---

## 二、快速开始

### 2.1 访问平台

- 云端访问：https://artifex.com.cn/login.html
- 本地访问：http://localhost:3000/login.html

### 2.2 注册账号

1. 打开登录页面
2. 点击页面底部的「立即注册」链接
3. 填写用户名、邮箱地址、密码（页面会实时显示密码强度指示）
4. 勾选「我同意服务条款和隐私政策」
5. 点击「创建账户」按钮完成注册

### 2.3 登录

1. 在登录页面输入邮箱地址和密码
2. （可选）勾选「记住我」以保持登录状态
3. 点击「登录账户」按钮

登录成功后将自动跳转至主控制台（Dashboard）。

## 三、功能说明

### 3.1 主控制台（Dashboard）

主控制台是登录后的默认首页，提供以下内容：

- **快捷工具入口**：包含「新建项目」「AI 生成」「素材库」三个快捷卡片，点击可直接跳转对应功能
- **最近项目**：展示最近创建或编辑的项目，点击可进入项目详情
- **搜索栏**：位于页面顶部，可搜索项目、素材或文档
- **通知消息**：点击顶部工具栏的铃铛图标查看系统通知
- **本地数据备份**：支持将项目列表、素材库、风格预设等数据导出为 JSON 备份文件，也可从之前导出的文件恢复数据

### 3.2 AI 图片生成

进入方式：点击左侧导航栏的「AI 生成」。AI 生成页面包含三个选项卡：**资产微调**、**图片生成**、**角色动作组**。

#### 3.2.1 资产微调

资产微调是一个内置的画布编辑器，类似 Photoshop 的操作体验，支持以下功能：

- **绘图工具**：移动（V）、画笔（B）、橡皮擦（E）、矩形选区（M）、油漆桶（G）、吸管（I）
- **画笔设置**：可调节画笔大小（1-64px）、不透明度（1%-100%）、填充容差、前景色
- **色彩调整**：支持调节亮度、对比度、饱和度
- **素材加载**：从素材库选择已有素材，或直接上传本地图片
- **AI 辅助功能**：
  - 局部重绘：用选区工具框选区域后，输入描述文本进行 AI 局部重绘
  - AI 扩图：将画布扩展到更大尺寸，AI 自动补全边缘内容，支持向四周、右、下、左、上方向扩展
  - 风格迁移：支持像素风格、水彩风格、油画风格、日式动漫、Q版卡通、写实风格、扁平矢量等多种风格
- **导出**：导出为 PNG 或保存回素材库
- **调色板**：可从当前画布提取调色板

#### 3.2.2 图片生成

切换到「图片生成」选项卡，支持以下生成模式：

**文生图**
1. 选择图片类型（UI界面、图标、按钮、卡片、导航栏、表单、背景图、插画）
2. 选择设计风格（现代简约、磨砂玻璃、像素风格、渐变色彩、暗黑模式、霓虹灯、扁平化、拟物化）
3. 选择配色方案（蓝绿色系、紫色系、暖色调、冷色调、单色系、对比色、彩虹色、黑白灰）
4. 选择图片尺寸（256x256 小图标 / 512x512 标准 / 1024x1024 高清 / 1024x1792 竖屏 / 1792x1024 横屏）
5. 选择 API 服务商（即梦 Seedream 4.0 推荐 / 腾讯云 / 阿里云通义万相）
6. 输入描述文本（Prompt），支持「个性需求描述」和「专业 UI 生成 Prompt」两种模式
7. 可选：使用游戏 UI 模板快速填入 Prompt
8. 选择生成数量（1/2/4/8 张）
9. 点击「开始生成图片」

**图生图（线稿/草图 -> 成品图）**
1. 切换到「线稿/草图 -> 成品图」模式
2. 上传线稿或草图（支持 JPG/PNG/WebP）
3. 输入描述文本，描述期望的上色或成图效果
4. 调整生成自由度（0.3-0.9，越小越贴近线稿）
5. 点击「开始生成图片」

**风格迁移**
1. 切换到「风格迁移」模式
2. 上传内容图（将应用风格的原始图片）
3. 上传风格参考图（提供艺术风格的图片）
4. 调整风格强度（0.2-0.9，越大风格越明显）
5. 点击「开始生成图片」

**图片放大**
1. 切换到「图片放大」模式
2. 上传需要放大的低分辨率图片
3. 选择放大倍数（2x / 4x）
4. 点击「开始生成图片」

**背景去除**
1. 切换到「背景去除」模式
2. 上传需要去除背景的图片
3. 点击「开始生成图片」
4. 输出为透明背景 PNG

#### 3.2.3 角色动作组

切换到「角色动作组」选项卡，用于批量生成游戏角色的三视图和动作帧动画。该功能仅使用即梦 Seedream 服务商。

**第一步：生成三视图**
1. 上传角色线稿/草图（白底黑线或清晰草图均可）
2. 选择三视图预设（像素风横板三视图 / 游戏立绘三视图 / 简约三视图 / 自定义）
3. 选择输出尺寸（1024x1024 / 1280x720 / 1536x640 横板三格）
4. 设置图生图强度（0.25-0.85，越低越贴近草图轮廓）
5. （可选）输入附加提示词（如：古风襦裙、双马尾、手持木剑等）
6. 点击「生成三视图」
7. 生成完成后可下载 PNG、打包 ZIP 或保存到素材库

**第二步：生成动作组**
1. 输入人物动作详细提示词（与动作类型二选一），或选择动作类型（待机、跑、跳、攻击，可多选）
2. 选择动作组画风/规范预设（像素+Q版精灵推荐 / 像素+略高细节 / 扁平2D游戏立绘 / 不追加）
3. 设置每动作帧数（2/4/8 帧）
4. 设置单帧尺寸（960x960 / 1024x1024 / 1280x720）
5. 点击「批量生成动作组」

**第三步：导出**
生成完成后支持多种导出格式：
- **Spritesheet (PNG)**：适用于 Unity、Godot 的 2D Spritesheet/Animation 工作流
- **Credits (JSON)**：适用于自研工具链、Unity/Godot 导入脚本读取元数据
- **ZIP 按动作**：适用于 Unity、Godot、Cocos 按动作目录批量导入
- **ZIP 按帧**：适用于通用引擎与 DCC 工具逐帧检查/导入

此外还可将 Spritesheet 或全部帧保存到素材库。

### 3.3 项目管理

#### 3.3.1 创建项目

1. 进入「项目管理」页面（点击左侧导航栏的「项目管理」）
2. 点击「新建项目」
3. 填写项目名称、描述、类型等信息
4. 点击「创建」

#### 3.3.2 项目详情

进入项目详情页后可以：
- 查看项目基本信息
- 管理项目关联素材
- 查看版本历史记录
- 从项目详情跳转到 AI 生成页面，生成的资产将自动关联到当前项目

### 3.4 素材库

#### 3.4.1 上传素材

1. 进入「素材库」页面（点击左侧导航栏的「素材库」）
2. 点击「上传素材」
3. 选择本地文件
4. 填写素材名称、分类、标签等信息
5. 确认上传

#### 3.4.2 搜索与筛选

- **关键词搜索**：在搜索框中输入关键词快速查找素材
- **分类筛选**：按素材分类进行筛选
- **标签筛选**：按标签进行筛选

#### 3.4.3 下载素材

1. 在素材库中选择目标素材
2. 点击「下载」按钮

### 3.5 用户中心

进入方式：点击左侧导航栏的「账户」。用户中心包含以下选项卡：

#### 3.5.1 个人信息

- 查看并修改昵称、性别、个人简介
- 查看用户 ID（只读）和身份角色
- 查看电子邮箱（只读）
- 选择国家/地区
- 语言切换：支持简体中文、繁體中文、English、日本語、한국어 五种语言

#### 3.5.2 API 密钥配置

1. 切换到「API 设置」选项卡
2. 选择 AI 服务商（腾讯云、阿里云、即梦等）
3. 填写对应的 API 密钥
4. 点击「验证」按钮检查密钥有效性
5. 点击「保存」

> 提示：也可以在服务端 `config/.env` 文件中统一配置 API 密钥（如 `JIMENG_API_KEY`、`DASHSCOPE_API_KEY` 等），配置后需重启后端服务。

#### 3.5.3 修改密码

1. 切换到「修改密码」选项卡
2. 输入当前密码
3. 输入新密码（需满足密码强度要求）
4. 确认新密码
5. 点击「修改密码」

密码要求：
- 至少 8 个字符
- 包含大小写字母
- 包含数字
- 可选包含特殊字符以增强安全性

#### 3.5.4 头像上传

1. 切换到「头像上传」选项卡
2. 点击头像区域选择图片文件
3. 预览并确认上传
4. 支持删除已上传的头像

#### 3.5.5 活动日志

切换到「活动日志」选项卡，可查看账户的操作历史记录，包括项目创建、素材上传、图片生成、登录等活动的时间线。

### 3.6 风格预设

进入方式：点击左侧导航栏的「风格预设」。

- **预设列表**：查看已保存的风格预设
- **创建自定义预设**：在 AI 生成页面中，通过「详细选项」面板选择参考图并点击「提取画风」，然后保存为命名预设
- **应用预设**：在 AI 生成页面顶部的风格预设下拉框中选择已保存的预设，预设内容会自动合并到 Prompt 中
- **删除预设**：在风格预设页面或 AI 生成页面的详细选项面板中删除不需要的预设

### 3.7 消息中心

- **系统通知**：查看平台系统公告、更新通知等
- **操作记录**：查看个人操作相关的通知消息
- 点击顶部工具栏的铃铛图标可快速查看通知，支持「全部已读」操作

## 五、常见问题

### 5.1 生成图片失败

- 检查 API 密钥是否在「用户中心 - API 设置」或服务端 `config/.env` 中正确配置
- 检查网络连接是否正常
- 检查所选 AI 服务商是否可用
- 即梦 Seedream 对图片尺寸有最低像素要求（921600 像素），请确保选择的尺寸满足要求
- 如使用阿里云通义万相，请确认已在服务端配置 `DASHSCOPE_API_KEY`

### 5.2 上传素材失败

- 检查文件大小是否符合限制
- 检查文件格式是否受支持（常见支持格式：JPG、PNG、WebP）
- 检查网络连接

### 5.3 忘记密码

- 在登录页面点击「忘记密码」链接
- 按提示输入邮箱地址并完成验证
- 如无法自行重置，请联系管理员

### 5.4 本地数据丢失

- 建议定期使用主控制台的「导出 JSON 备份」功能备份本地数据
- 如数据丢失，可使用「从文件导入」功能恢复之前导出的备份

### 5.5 角色动作组生成速度慢

- 角色动作组需要为每个动作的每一帧单独调用 AI 生成，帧数越多耗时越长
- 建议先用少量帧数（2帧）测试效果，确认满意后再增加帧数批量生成
- 确保即梦 API 密钥配置正确且账户额度充足

### 5.6 风格预设提取失败

- 风格提取功能需要在服务端配置 `DASHSCOPE_API_KEY`（阿里云通义多模态 API）
- 确保上传的参考图格式正确（支持 JPG/PNG/WebP）
