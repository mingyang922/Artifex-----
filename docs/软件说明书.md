# Artifex 二维游戏美术协作与 AI 资产生成平台 V1.0.0

## 软件说明书

---

### 一、软件概述

Artifex 是一款面向 2D 游戏美术资产生产的协作平台，集成了 AI 辅助生成、项目管理、素材库管理和用户中心等功能模块。平台旨在帮助游戏美术团队高效完成从概念设计到资产产出的全流程工作，降低美术资源制作成本，提升协作效率。

**软件名称：** Artifex 二维游戏美术协作与 AI 资产生成平台  
**版本号：** V1.0.0  
**开发语言：** JavaScript / HTML / CSS  
**运行环境：** Node.js 22+，支持 Windows / macOS / Linux  
**数据库：** SQLite  
**许可证：** MIT  

---

### 二、功能模块说明

#### 2.1 用户登录与鉴权

- 支持用户注册、登录、登出功能
- 基于 Session Cookie 的会话管理
- 密码采用 bcrypt 加密存储
- 用户 API 密钥采用 AES-256-CBC 加密存储
- 支持密码修改功能
- 管理员与普通用户角色区分
- 赛博朋克视觉风格登录页：动态渐变、网格叠加、玻璃拟态卡片、霓虹 Logo

#### 2.2 主控制台（Dashboard）

- 项目总览与快速入口
- 最近项目展示（从服务端动态加载）
- 功能导航：AI 生成、项目管理、素材库、用户中心
- Canvas 粒子网络背景，支持鼠标交互与自适应粒子密度
- 通知消息中心

#### 2.3 AI 游戏资产生成

- **文生图功能：** 基于文本描述生成游戏美术资产
- **支持资产类型：** 角色立绘、场景概念图、道具/技能图标、UI 元素等
- **游戏风格预设：** 二次元、像素风、赛博朋克、国风、欧美写实等
- **提示词模板：** 提供常用游戏美术场景的提示词模板，支持一键使用
- **代码生成：** 基于混元大模型生成 HTML/CSS 代码（UI 原型）
- **生成结果管理：** 预览、下载、一键加入素材库
- **用量追踪：** 记录每次 API 调用，支持配额管理

#### 2.4 项目管理

- 项目创建、编辑、删除（全部通过服务端 API 完成）
- 项目详情页：从服务端加载项目数据，查看项目描述、关联资产
- 项目资产关联：将素材库中的资产绑定到项目
- 服务端持久化存储（数据库）
- 项目版本历史记录
- 删除操作经服务端确认后再移除，防止误删

#### 2.5 素材库

- 素材分类管理：角色、场景、道具、UI 等类别
- 素材信息：名称、描述、图片、分类、标签
- 素材预览与下载
- 从 AI 生成结果一键导入
- 支持 imageUrl 外部链接引用
- 服务端持久化存储
- 单个素材内容上限 10MB，超限返回 413 错误

#### 2.6 用户中心

- 个人信息管理（头像、昵称、简介）
- API 密钥配置：支持多家服务商（腾讯混元、阿里通义万相、即梦 Seedream 等）
- API 密钥验证：自动检测密钥有效性
- API 密钥状态查看
- 用户配额管理与用量统计
- 技术风格偏好设置

#### 2.7 管理员面板

- 用户列表查看与管理
- 用量统计与分析
- 配额分配与调整

#### 2.8 通知系统

- 站内消息通知（演示功能）
- 消息中心页面（链接指向用户中心）
- 通知组件（弹窗提醒）

### 三、技术架构

#### 3.1 系统架构

```
┌─────────────────────────────────────────────────┐
│                   前端层                         │
│  HTML/CSS/JS（原生，无框架依赖）                  │
│  login.html / dashboard.html / modules/*        │
└───────────────────┬─────────────────────────────┘
                    │ HTTP API
┌───────────────────▼─────────────────────────────┐
│                  后端层                          │
│  Node.js + Express                              │
│  backend/proxy.js（主入口）                      │
│  backend/lib/（鉴权、配置、限流等）              │
│  backend/db/（数据库操作）                       │
└───────────────────┬─────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────┐
│                 数据层                           │
│  SQLite（用户、项目、素材、用量日志等）           │
└─────────────────────────────────────────────────┘
```

#### 3.2 技术选型说明

| 技术 | 用途 | 选型理由 |
|------|------|----------|
| Node.js 22 | 运行环境 | LTS 版本，性能稳定，生态丰富 |
| Express | Web 框架 | 轻量、成熟、社区活跃 |
| SQLite | 数据库 | 零配置、单文件部署、适合中小规模 |
| bcryptjs | 密码加密 | 纯 JS 实现，无需编译原生模块 |
| Helmet | 安全中间件 | 自动设置 HTTP 安全头 |
| better-sqlite3 | SQLite 驱动 | 高性能同步 API |

#### 3.3 视觉设计

- 赛博朋克主题风格，深色背景配霓虹青/紫渐变色系
- Canvas 粒子网络背景（`particle-network.js`），支持鼠标交互、自适应粒子密度、`prefers-reduced-motion` 降级
- 登录页：动态渐变、网格叠加、玻璃拟态卡片、光带扫过动画
- 主控制台：鼠标追踪光晕、侧栏边缘流光、顶栏光晕呼吸
- 自定义主题滚动条，全局统一 Orbitron/Rajdhani 字体

### 四、API 接口说明

#### 4.1 认证接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/register | 用户注册 |
| POST | /api/auth/login | 用户登录 |
| POST | /api/auth/logout | 用户登出 |
| GET | /api/me | 获取当前用户信息 |
| PUT | /api/me/profile | 更新用户资料 |
| POST | /api/me/change-password | 修改密码 |

#### 4.2 API 密钥管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/me/api-settings | 获取 API 密钥配置 |
| GET | /api/me/api-settings/status | 检查密钥状态 |
| PUT | /api/me/api-settings | 更新 API 密钥 |

| POST | /api/me/api-settings/validate | 验证密钥有效性 |

#### 4.3 AI 生成接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/image-proxy | AI 图片生成（文生图/图生图） |
| GET | /api/proxy-image | 图片代理（SSRF 防护） |

#### 4.4 项目管理接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects | 获取项目列表 |
| POST | /api/projects | 创建项目 |
| PUT | /api/projects/:id | 更新项目 |
| DELETE | /api/projects/:id | 删除项目 |

#### 4.5 素材库接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/projects/:id/assets | 向项目添加素材（上限 10MB） |
| DELETE | /api/assets/:id | 删除素材 |

### 五、安全特性

- **密码安全：** bcrypt 哈希加密存储
- **API 密钥安全：** AES-256-CBC 加密存储，读取时自动解密
- **会话安全：** Session Cookie，生产环境强制 secure 标志
- **SSRF 防护：** 图片代理接口校验 URL，禁止访问内网地址
- **XSS 防护：** 前端输出转义（`escapeHtml`），项目详情页与图片生成器 innerHTML 注入均做转义处理
- **素材体积限制：** 服务端素材接口限制单个素材不超过 10MB
- **HTTP 安全头：** Helmet 中间件自动设置
- **接口限流：** 按用户限流（图片生成每分钟 10 次）
- **配额管理：** 超限返回 429 状态码

### 六、部署方式

#### 6.1 本地运行

1. 安装 Node.js 22+
2. 执行 `npm install`
3. 执行 `npm start`
4. 访问 `http://localhost:3000`

#### 6.2 生产部署

- 支持腾讯云单服务器部署
- Nginx 反向代理
- 域名配置（已适配 artifex.com.cn）
- 环境变量配置（SESSION_SECRET、ALLOWED_ORIGINS 等）
