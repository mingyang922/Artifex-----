# Artifex 二维游戏美术协作与 AI 资产生成平台 软件说明书

## 1 软件概述

### 1.1 软件名称

- 软件全称：Artifex 二维游戏美术协作与 AI 资产生成平台
- 软件简称：Artifex
- 版本号：V1.0.0
- 开发方式：合作开发（三人团队）
- 开发者：[开发者1]、[开发者2]、[开发者3]

### 1.2 软件用途

Artifex 是一款面向 2D 游戏美术团队的协作平台，集成了 AI 图片生成、素材管理、项目管理和角色动作组生成等核心能力。平台旨在帮助游戏美术人员快速完成从概念草图到成品素材的生产流程，支持多人协作与资产沉淀。

### 1.3 主要功能

| 功能模块 | 说明 |
|---------|------|
| 用户登录与注册 | 邮箱注册、密码登录、会话鉴权 |
| AI 图片生成 | 文生图、图生图（线稿转成品），支持腾讯混元、阿里通义万相、即梦 Seedream、SD Web UI 等多个 AI 服务商 |
| 角色动作组生成 | 三视图生成、多帧动作序列生成、Spritesheet 导出 |
| 项目管理 | 创建项目、管理素材、项目详情编辑 |
| 素材库 | 素材浏览、搜索、分类管理 |
| 风格预设 | 预设管理与应用 |
| 资产微调 | 画布级像素编辑（画笔、橡皮、油漆桶、吸色、选区、撤销/重做） |
| 用户中心 | 个人信息管理、头像设置、API 凭证配置、密码修改 |

### 3.1 总体架构

Artifex 采用前后端同仓架构，前端为原生 HTML/CSS/JavaScript，后端为 Node.js + Express + SQLite。

│  └────┬─────┘ └────┬─────┘ └────┬─────┘        │
│       │            │            │                │
│       └────────────┼────────────┘                │
│                    │ fetch API                   │
└────────────────────┼────────────────────────────┘
                     │
┌────────────────────┼────────────────────────────┐
│               Node.js 服务端                     │
│  ┌─────────────────┼─────────────────┐          │
│  │           Express 路由             │          │
│  │  /api/auth/*  /api/me/*           │          │
│  │  /api/image-proxy  /api/health    │          │
│  └─────────────────┬─────────────────┘          │
│       ┌────────────┼────────────┐               │
│  ┌────┴────┐ ┌─────┴────┐ ┌────┴────┐          │
│  │ SQLite  │ │ AI 提供商 │ │ 静态文件 │          │

## 4 功能模块详细说明

### 4.1 用户登录与注册

**功能描述：** 支持用户通过邮箱注册账户并登录系统。

**操作流程：**

1. 打开系统首页，进入登录页面
2. 新用户点击「注册」选项卡，填写用户名、邮箱、密码（不少于 6 位）
3. 点击「创建账户」完成注册，系统自动登录并跳转至仪表盘
4. 已注册用户输入邮箱和密码，点击「登录」进入系统

**技术实现：**
- 密码使用 bcrypt 算法加密存储于 SQLite 数据库
- 登录成功后通过 express-session 创建会话，Cookie 有效期 14 天
- 登录/注册接口启用 CSRF 令牌校验和会话固定攻击防护

### 4.2 主仪表盘

**功能描述：** 登录后的主界面，提供快捷入口和系统概览。

**主要元素：**
- 顶部导航栏：包含通知按钮、用户头像
- 侧边栏：AI 生成、项目管理、素材库、风格预设、用户中心等导航链接
- 快捷工具卡片：快速跳转到各功能模块
- 项目概览区域

### 4.3 AI 图片生成

**功能描述：** 通过 AI 服务商生成 2D 游戏美术素材。

**子功能：**

#### 4.3.1 文生图
1. 输入描述文字（提示词）
2. 选择 AI 服务商（腾讯混元 / 阿里通义万相 / 即梦 Seedream / SD Web UI）
3. 设置图片尺寸、风格等参数
4. 点击「生成」获取 AI 生成的图片

#### 4.3.2 图生图
1. 上传线稿或草图
2. 调节生成强度（控制与原图的相似度）
3. 输入补充描述
4. 点击「生成」将线稿转为成品图

#### 4.3.3 Prompt 模式
- 个性需求描述模式：直接使用用户输入
- 专业 UI 生成 Prompt 模式：先调用通义千问将中文描述转化为专业英文 Prompt，再生成图片

**技术实现：**
- 后端 `/api/image-proxy` 统一代理各 AI 服务商接口
- 支持用户在用户中心自行配置 API 凭证
- `free/mock` 模式仅管理员可用，用于调试

### 4.4 角色动作组生成

**功能描述：** 为 2D 游戏角色生成三视图和多帧动作序列。

**操作流程：**

1. **三视图生成**
   - 上传角色线稿或输入角色描述
   - 选择输出尺寸
   - 点击「生成三视图」获取正面、侧面、背面视图

2. **动作组生成**
   - 基于三视图，选择动作类型（待机、行走、奔跑、攻击等）
   - 输入动作详细提示词
   - 点击「生成动作组」获取多帧动作序列

3. **导出**
   - 下载单帧 PNG
   - 导出 Spritesheet（拼合所有帧为一张图）
   - 导出 JSON 元数据
   - 导出 ZIP 压缩包

**技术实现：**
- 使用即梦 Seedream 作为生成服务
- 跨帧状态缓存保证角色一致性
- 三视图正面裁切作为后续动作生成的参考

### 4.5 项目管理

**功能描述：** 创建和管理游戏美术项目，组织项目素材。

**操作流程：**
1. 点击「新建项目」创建项目，填写项目名称和描述
2. 在项目详情中查看和管理素材
3. 支持从 AI 生成结果直接添加到项目
4. 支持本地文件上传到项目

### 4.6 素材库

**功能描述：** 集中管理所有 AI 生成和上传的美术素材。

**操作流程：**
1. 浏览素材列表，支持按类型筛选
2. 点击素材查看大图预览
3. 支持素材的删除和导出

### 4.7 风格预设

**功能描述：** 管理和应用 AI 生成的风格预设。

**操作流程：**
1. 创建风格预设，设置风格参数
2. 在 AI 生成时选择预设应用对应风格

### 4.8 资产微调

**功能描述：** 对素材进行像素级编辑。

**主要工具：**
- 画笔：自定义大小和颜色的像素绘制
- 橡皮：擦除像素
- 吸色：从画布取色
- 油漆桶：区域填充（支持容差调节）
- 选区：选择区域进行操作
- 缩放/拖拽：画布缩放和平移
- 撤销/重做：操作历史回退
- 导出 PNG：保存编辑结果
- 保存到素材库：将编辑结果存入素材库

### 4.9 用户中心

**功能描述：** 管理个人信息和系统设置。

**功能项：**
- 个人信息编辑（昵称、性别、简介、国家/地区、语言）
- 头像管理（上传、更换、删除、历史记录）
- 密码修改（带强度检测和双重验证模拟）
- API 凭证配置（各 AI 服务商的密钥管理）

## 5 安装与部署

### 5.1 本地安装

**步骤 1：安装 Node.js**

下载并安装 Node.js 22 LTS（推荐 22.22.0）：
```
https://nodejs.org/
```

**步骤 2：安装项目依赖**

在项目根目录执行：
```bash
npm install
```

**步骤 3：配置环境变量**

复制环境变量模板并填写 API 密钥：
```bash
cp backend/.env.example backend/.env
```

编辑 `backend/.env`，填入各 AI 服务商的 API 密钥。

**步骤 4：启动服务**

```bash
npm start
```

或在 Windows 下双击 `一键启动.cmd`。

**步骤 5：访问系统**

打开浏览器访问：`http://localhost:3000/login.html`

### 5.2 云服务器部署

**环境要求：**
- Ubuntu 20.04+ / CentOS 7+
- Node.js 22 LTS
- Nginx
- PM2（进程守护）

**部署步骤：**

1. 安装 Node.js 22
2. 上传项目文件到服务器
3. 执行 `npm install` 安装依赖
4. 配置 `.env` 环境变量
5. 使用 PM2 启动：`pm2 start backend/proxy.js --name artifex`
6. 配置 Nginx 反向代理（参考 `docs/DEPLOY_TENCENT_SINGLE_SERVER.md`）
7. 如需 HTTPS，使用 certbot 申请证书

## 6 系统配置

### 6.1 环境变量说明

| 变量名 | 必填 | 说明 |
|--------|------|------|
| SESSION_SECRET | 生产环境必填 | 会话加密密钥 |
| ALLOWED_ORIGINS | 生产环境必填 | CORS 允许的源（逗号分隔） |
| HUNYUAN_SECRET_ID | 否 | 腾讯混元 SecretId |
| HUNYUAN_SECRET_KEY | 否 | 腾讯混元 SecretKey |
| DASHSCOPE_API_KEY | 否 | 阿里通义 API Key |
| JIMENG_API_KEY | 否 | 即梦 Seedream API Key |
| SD_WEBUI_URL | 否 | SD Web UI 地址（默认 http://127.0.0.1:7860） |
| PORT | 否 | 服务端口（默认 3000） |

### 6.2 用户级 API 配置

普通用户可在「用户中心 → API 设置」中自行配置各服务商凭证，无需修改服务器环境变量。配置后该用户的 AI 请求将使用其个人凭证。

## 7 技术特点

1. **多服务商支持**：同时对接腾讯混元、阿里通义万相、即梦 Seedream、SD Web UI 四个 AI 服务商，用户可按需选择
2. **用户级隔离**：每个用户独立的 API 凭证、素材存储和项目数据
3. **像素级编辑**：内置画布编辑器支持真正的像素级操作（Bresenham 逐像素绘制、禁用抗锯齿）
4. **安全机制**：bcrypt 密码加密、CSRF 防护、会话固定防护、XSS 防护、SSRF 防护
5. **响应式设计**：适配不同屏幕尺寸，支持移动端菜单
