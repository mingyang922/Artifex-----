# Artifex 安全审计文档 V1.3.3

## 一、概述

本文档记录 Artifex 平台在 V1.4.0 版本中的安全特性和审计结果。

## 二、安全架构

### 2.1 认证与授权

- **密码存储：** bcrypt 哈希加密，10 轮 salt
- **会话管理：** express-session，HttpOnly + Secure + SameSite=Lax
- **CSRF 防护：** Double-Submit Cookie 模式，所有写操作需携带 CSRF Token
- **角色系统：** 管理员/普通用户，仅信任数据库 role 列

### 2.2 数据加密

- **算法：** AES-256-GCM（认证加密，防篡改）
- **密钥管理：** 环境变量 `ENCRYPTION_KEY` 或 `SESSION_SECRET`
- **加密字段：** API Key、SecretKey、SecretId
- **向后兼容：** 支持解密旧版 AES-256-CBC 格式

### 2.3 网络安全

- **HTTPS：** 生产环境强制 HTTPS
- **CSP：** 严格的 Content-Security-Policy
- **CORS：** 生产环境白名单机制
- **Helmet：** 自动设置安全响应头

## 三、漏洞防护

### 3.1 SQL 注入

**防护措施：**

- 使用 better-sqlite3 参数化查询
- 所有用户输入通过参数绑定
- 不使用字符串拼接 SQL

**审计结果：** ✅ 未发现 SQL 注入漏洞

### 3.2 XSS（跨站脚本）

**防护措施：**

- 前端输出统一使用 `escapeHtml()` 转义
- CSP 限制脚本来源
- HttpOnly Cookie 防止 JS 访问

**审计结果：** ✅ 未发现 XSS 漏洞

### 3.3 CSRF（跨站请求伪造）

**防护措施：**

- Double-Submit Cookie 模式
- 所有写操作（POST/PUT/DELETE）需携带 CSRF Token
- Token 有效期 1 小时

**审计结果：** ✅ 未发现 CSRF 漏洞

### 3.4 SSRF（服务端请求伪造）

**防护措施：**

- URL 协议白名单（仅 http/https）
- IP 黑名单（内网地址、云元数据）
- DNS 解析后二次校验（防 DNS rebinding）
- 响应大小限制（20MB）
- Content-Type 白名单（仅图片类型）

**审计结果：** ✅ 未发现 SSRF 漏洞

### 3.5 暴力破解

**防护措施：**

- 登录限流：20 次/15 分钟
- 修改密码限流：5 次/15 分钟
- 图片生成限流：10 次/分钟
- 全局 API 限流：120 次/分钟

**审计结果：** ✅ 限流机制有效

### 3.6 会话安全

**防护措施：**

- Session ID 随机生成
- 登录/注册后重新生成 Session
- HttpOnly Cookie 防止 JS 访问
- Secure Cookie（生产环境）
- SameSite=Lax 防止 CSRF

**审计结果：** ✅ 会话安全机制完善

## 四、输入验证

### 4.1 用户名

- 长度：2-32 字符
- 格式：字母、数字、下划线、中文
- 唯一性：数据库唯一约束

### 4.2 密码

- 最小长度：6 字符
- 存储：bcrypt 哈希
- 传输：HTTPS 加密

### 4.3 邮箱

- 格式验证
- 唯一性：数据库唯一约束
- 小写规范化

### 4.4 API 密钥

- 长度限制：4096 字符
- 加密存储：AES-256-GCM
- 传输：HTTPS 加密

### 4.5 素材内容

- 大小限制：10MB
- 格式验证：MIME 类型 + magic bytes
- 存储：SQLite TEXT（Data URL 或远程 URL），单项最大 10MB；列表摘要接口不返回素材正文

## 六、环境安全

### 6.1 环境变量

- `SESSION_SECRET`：会话密钥（生产环境必须设置）
- `ENCRYPTION_KEY`：用户 API 凭证加密密钥（生产环境建议独立设置并长期保存；Docker 部署必填）
- `ALLOWED_ORIGINS`：CORS 白名单（生产环境必须设置）
- `ADMIN_USER_ID`：显式指定管理员；未配置时不会自动提升首位注册用户
- `REGISTRATION_ENABLED`：是否开放注册，私有部署建议设为 `false`

### 6.2 敏感信息保护

- `.env` 文件不提交到仓库
- `.gitignore` 覆盖所有敏感文件
- API 密钥脱敏显示（仅显示后 4 位）

## 七、安全建议

### 7.1 生产环境

1. 设置强密码的 `SESSION_SECRET`
2. 配置 `ALLOWED_ORIGINS` 白名单
3. 启用 HTTPS
4. 定期更新依赖
5. 定期备份数据库

### 7.2 开发环境

1. 不使用生产环境的密钥
2. 定期清理测试数据
3. 不在代码中硬编码密钥

## 八、审计结论

Artifex V1.4.0 版本在安全性方面表现良好：

- ✅ 认证机制完善
- ✅ 数据加密到位
- ✅ 常见漏洞防护有效
- ✅ 输入验证严格
- ✅ 依赖安全无高危漏洞

建议在生产部署前完成：

1. 设置强密码的环境变量
2. 启用 HTTPS
